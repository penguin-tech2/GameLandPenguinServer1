# GameLand Penguin Music Library

Upload your `.m4a`, `.mp3`, or `.wav` instrumental audio files here:

- `public/music/country/` -> Country tracks
- `public/music/rap/` -> Rap & Hip-Hop beats
- `public/music/pop/` -> Pop & Synthwave tracks

Files placed here can be accessed directly in the browser via:
`/music/country/your-track.m4a`
`/music/rap/your-track.m4a`
`/music/pop/your-track.m4a`
